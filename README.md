# Table Summary（表格统计栏）

为 NocoBase 表格区块增加类似 Excel 的动态统计栏。

## 基本信息

- 包名：`@xiezuo/plugin-table-summary`
- 最低适配版本：NocoBase 2.2.10
- 客户端：V1 + V2（V2 优先）
- 作者：偕作BIM
- 官网：https://www.xzbim.cn
- 当前阶段：V1/V2 核心功能开发

## V1.0 目标

- 统计栏支持表格顶部或底部
- 支持计数、非空计数、合计、平均值、最大值、最小值
- 支持当前页和全部筛选结果两种统计范围
- 继承表格 Filter、Data Scope、变量、关联上下文及当前用户权限
- 统计结果跟随筛选、分页和数据变更刷新
- 兼容 NocoBase 2.2.* 的 V1 与 V2 页面

## 当前实现

- V1：表格区块设置中配置统计栏；字段设置中选择统计方式
- V2：FlowEngine 表格设置与字段设置中配置统计
- 当前页模式：在客户端计算当前已加载的数据
- 全部数据模式：通过服务端聚合计算，并继承表格筛选条件
- 权限：统计动作映射到原 Collection 的查看权限
- 数据源：自动向已加载及后续加载的数据源注册统计动作

> 当前版本仍处于开发阶段，尚未发布安装包。需要在 NocoBase 2.2.10 本地环境完成构建与界面验证。
