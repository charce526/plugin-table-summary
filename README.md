# Table Summary（表格统计栏）

为 NocoBase 表格区块增加类似 Excel 的动态统计栏。

## 基本信息

- 包名：`@xiezuo/plugin-table-summary`
- 最低适配版本：NocoBase 2.2.10
- 客户端：V1 + V2（V2 优先）
- 作者：偕作BIM
- 官网：https://www.xzbim.cn
- 当前阶段：技术验证与插件骨架

## V1.0 目标

- 统计栏支持表格顶部或底部
- 支持计数、非空计数、合计、平均值、最大值、最小值
- 支持当前页和全部筛选结果两种统计范围
- 继承表格 Filter、Data Scope、变量、关联上下文及当前用户权限
- 统计结果跟随筛选、分页和数据变更刷新
- 兼容 NocoBase 2.2.* 的 V1 与 V2 页面
